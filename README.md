# Fish Eye

Прототип аркадного хоррор-роглайта от первого лица для ПК-браузера (Vite + TypeScript + Three.js). Иди по зелёной линии к ГЛАЗУ, возвращайся по памяти к белой стене, уходи рывком от врага.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm test
npm run build
```

Управление: мышь — взгляд, WASD — движение, Space + A/D — рывок, Esc — пауза.
Кнопка `DBG` справа внизу — отладка. Параметры: `?debug=1&seed=123&god=1&timescale=0.5`.

## Документы

- `CLAUDE.md` — правила работы и инварианты кода.
- `docs/GDD.md` — геймдизайн, контракт по механикам.
- `docs/VISUAL.md` — визуальное направление, карта кода, грабли.
- `docs/FISH_EYE_Prototype_v0.md` — исходная спецификация прототипа (англ.).
- `docs/plans/` — текущий план.

## Как работаем

1. Идея → обсуждение → решение записываем в GDD или план до кода.
2. Реализация с тестами на симуляцию.
3. Проверка в браузере (Chrome DevTools), скриншот.
4. Плейтест → выводы в план.
5. Коммит по просьбе; push в `main` = деплой.
